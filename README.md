**Практическая работа № 3:** «Практикум работы с фреймворком Electron» (тема 2 «Кросс-платформенная разработка десктопных программ»)

Финансовый университет при Правительстве Российской Федерации, 2026

## Запуск

```bash
npm install
npm start
```

## Сборка дистрибутива

```bash
npm run dist
```

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.js` | главный процесс: жизненный цикл, окно, обработчики IPC `list-dir` и `save-note` |
| `preload.js` | скрипт предзагрузки: публикует `window.api` через `contextBridge` |
| `index.html`, `styles.css` | интерфейс приложения |
| `renderer.js` | процесс отрисовки: обработчики кнопок, вызовы `window.api` |
| `package.json` | манифест проекта, скрипты `start`/`dist`, настройки electron-builder |
